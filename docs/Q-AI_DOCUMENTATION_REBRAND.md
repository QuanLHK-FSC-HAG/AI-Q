# AI-Q Documentation Rebrand

- Public repository: https://github.com/QuanLHK-FSC-HAG/AI-Q
- Scope completed: root README translations, public package/service READMEs, and website documentation (`services/site/src/docs`).
- Product prose `AI-Q` was changed to `AI-Q`.
- Public home, documentation, download, Discord, X, and upstream repository navigation links were redirected to the AI-Q repository or its Releases/Discussions pages.
- Fenced and inline code were intentionally preserved. They can contain compatibility-critical commands, package namespaces, API symbols, schema paths, environment variables, and protocol identifiers.
- `LICENSE`, `NOTICE`, engineering `AGENTS.md`, internal `.AIQ/` instructions, and specs were intentionally not rewritten.
