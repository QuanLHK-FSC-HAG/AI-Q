AI-Q tập trung vào trải nghiệm gọn, rõ ràng trên Windows: cài nhanh, dùng ngay, dễ kiểm soát.

01

aiq/auto mặc định

Tự động định tuyến đến model khả dụng, giúp bạn bắt đầu làm việc mà không cần cấu hình phức tạp.

02

Không cần tài khoản AI

Mở app là dùng được ngay với luồng khởi động đơn giản, phù hợp cho người dùng Windows.

03

1 file cài đặt

Chỉ cần tải một file `.exe` mới nhất. Bộ cài tự tải CLI cần thiết khi có Internet.

04

Cập nhật model/mix

Dữ liệu AI-Q độc lập

AI-Q quản lý dữ liệu riêng để vận hành ổn định trên máy của bạn, kể cả khi máy có nhiều ứng dụng khác.

Cài đặt trong 3 bước

Chỉ cần file cài đặt mới nhất, bạn có thể bắt đầu dùng AI-Q trong vài phút.

1

Tải bộ cài

Tải file AI-Q-Setup-win-x64.exe mới nhất từ nút tải trên trang này.

2

Cài đặt

Chạy bộ cài, chọn thư mục và nhập tên người dùng. Cần Internet để tải CLI khi cài.

3

Bắt đầu dùng

Mở AI-Q và làm việc ngay với model mặc định aiq/auto.
