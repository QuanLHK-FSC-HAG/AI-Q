Tính năng chính

Tập trung vào trải nghiệm đơn giản cho người dùng Windows: cài nhanh, dùng ngay, tự chọn model phù hợp.

aiq/auto mặc định

Tự động định tuyến đến model khả dụng, giảm thời gian cấu hình và giúp bạn bắt đầu làm việc ngay.

Không cần tài khoản AI

Trải nghiệm khởi động gọn nhẹ, không cần tạo tài khoản AI riêng để bắt đầu sử dụng.

1 file cài đặt

Tải một file `.exe`, chạy cài đặt trên Windows. Bộ cài tự tải CLI cần thiết khi có Internet.

Hỗ trợ tiếng Việt

Giao diện và trải nghiệm hướng tới người dùng Việt Nam, dễ tiếp cận và dễ sử dụng.

Cập nhật model/mix

Cập nhật model/mix ngay trong ứng dụng bằng một nút bấm, không cần cài lại toàn bộ app.

Tách biệt dữ liệu

Dữ liệu AI-Q được cô lập khỏi OpenCode để tránh xung đột khi máy đã cài cả hai ứng dụng.

Cài đặt trong 3 bước

Bạn có thể bắt đầu sử dụng AI-Q trên Windows chỉ trong vài phút.

1

Tải bộ cài

Tải AI-Q-Setup-win-x64.exe từ GitHub Releases hoặc nút tải trên trang này.

2

Cài đặt

Chạy file cài đặt, chọn thư mục cài và nhập tên người dùng. Cần Internet để tải CLI khi cài.

3

Bắt đầu dùng

Mở AI-Q, dùng aiq/auto làm model mặc định và bắt đầu trò chuyện/lập trình ngay.
